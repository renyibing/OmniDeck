# OmniDeck 文档目录

本文档目录整理了 OmniDeck 多设备控制中心当前阶段的核心设计资料，基于 2026-08-12 的代码实现状态。

## 文档列表

- `requirements-analysis.md`
  说明业务背景、目标、范围、功能性与非功能性需求、约束、验收口径。
- `detailed-design.md`
  说明系统架构、模块职责、数据模型、协议设计、投屏可操控链路、多真机绑定方案与演进建议。
- `wda-local-setup.md`
  说明本机 iOS WebDriverAgent 的启动、停止、端口映射与 OmniDeck 配置方式。

## 适用范围

当前文档覆盖以下主题：

- Android/iOS 多设备监控墙
- 设备会话隔离与批量任务调度
- 截图驱动的 AI 观察链路
- 人工接管下的投屏点击操控
- 1 台 Android + 2 台 iOS 的真机绑定模式

## 说明

- 文档描述的是当前仓库已实现能力与明确边界，不把尚未实现的 WebRTC/MSE 视频网关写成既成事实。
- 真机验收口径仍遵循仓库约束：未达到 8 台授权设备前，不声明真实硬件规模验收完成。
